## 4. C가 Lazy에서 아직 낮은 이유 (E3 상세·E4·E5)

**수비는 좋아졌다 [사실]** — 같은 종류의 공에서 내 받기가 떨어지는 몫:

| 시드 | B | C |
|---|---|---|
| 16 | 0.068 | 0.026 |
| 32 | 0.042 | 0.014 |

**공격은 그대로다 [사실]** — Lazy에서 적 받기는 B 0.86~0.87, C 0.87로 같다.

**득점용 공이 사라진다 (E4) [사실]** — 적이 받으려면 움직여야 하는 거리가 20~35인 공:

| 시드 | base: 비율 / 적 받기 | Lazy: 비율 / 적 받기 |
|---|---|---|
| B s16 | 0.25 / 0.06 | 0.05 / 0.95 |
| C s16 | 0.25 / 0.11 | 0.05 / 0.92 |
| B s0 | 0.03 / 0.67 | 0.04 / 0.82 |
| C s0 | 0.05 / 0.95 | 0.05 / 0.96 |

- [사실] Lazy에서 적 받기가 오른 몫(0.21~0.24) 가운데 0.13~0.18이 공 위치 구성이 바뀐 몫이다.
- [사실] 이 득점용 공에 기대는 정도가 붕괴와 맞아떨어진다. seed0은 3~5%만 쓰고 멀쩡하다. seed16·32는 24~29%를 쓰고 무너진다.

**base 적은 늘 공 높이에 있다 (E5) [사실, 측정 2개]**

| | 치는 순간 공y–적y 상관 | 치는 순간 \|공y−적y\| | 공이 오는 동안 상관 |
|---|---|---|---|
| base | 0.98~0.99 | 3.4~4.5 | 0.99 |
| Lazy | −0.23~−0.11 | 48~53 | −0.17~0.20 |

## 5. 개입 실험 (E6, 판정 기준은 실행 전 고정)

Lazy에서 내가 받아친 순간에만 적 위치를 바꿔 놓는다.

| | base | Lazy | Lazy + 공 높이로 | Lazy + 무작위 (대조군) |
|---|---|---|---|---|
| B s16 | 19.35 | 2.40 | 13.55 | 15.90 |
| B s32 | 19.40 | 5.40 | 14.00 | 12.15 |
| C s16 | 18.95 | 9.15 | 14.80 | 16.70 |
| C s32 | 19.05 | 11.00 | 12.90 | 15.85 |

- 판정: seed16·32에서 공 높이 17점 이상이고 무작위 17점 미만이면 원인 확정 → 0/4 → **미확정**
- [사실] 적을 어디로 옮기든 크게 회복된다(+3~13). 무작위로 옮겨도 공 높이와 비슷하거나 더 많이 회복된다.
- [해석] "적이 공 높이에 있다는 관계가 깨져서 무너졌다"는 가설은 지지되지 않아 **철회**한다. E5의 상관 자체는 사실이지만 원인이라는 증거는 아니다.
- [새 가설, 미검증] Lazy 적이 마지막에 받아친 자리에 멈춰 있는 것이 핵심일 수 있다.
- [실험 결함] 적을 옮긴 횟수가 판당 정확히 21번 더 많다. 득점 뒤 서브 때마다 한 번씩 더 옮겨졌다. 두 조건에 똑같이 걸려서 공 높이와 무작위의 비교는 공정하다.
